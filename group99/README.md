## HTTPS Hosting and Phone Testing

Browsers restrict camera access to secure origins (`localhost` or `HTTPS`). To test the application on a smartphone:

1. **Host via HTTPS:**
   - **Netlify Drop:** Visit `app.netlify.com/drop` and drag the project folder to deploy instantly to a free HTTPS URL.
   - **GitHub Pages:** Push the project to a GitHub repository, enable GitHub Pages under repository Settings > Pages (set the source branch to `main`), and wait for the live HTTPS link.
2. **Phone Testing:**
   - Open the generated HTTPS URL on your smartphone browser (Chrome, Edge, or Safari).
   - When prompted, grant camera permissions.
   - Aim your camera at a printed or displayed Hiro marker to view and interact with the 3D greeting card scene.
